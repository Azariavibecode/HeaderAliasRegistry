# API v1 to v2 migration

## MIGRATION X-Request-Trace TO Retry-Delay

No compatible rename exists. `Retry-Delay` is a response timing list in milliseconds and does not replace the request correlation header.

## MIGRATION X-Request-Trace TO Request-Correlation

This alternative candidate preserves the same request-correlation purpose, single opaque UTF-8 value model and non-credential security boundary.

## MIGRATION X-Legacy-Trace TO Trace-Context

This legacy candidate preserves the same request-correlation purpose, single opaque UTF-8 value model and non-credential security boundary.
